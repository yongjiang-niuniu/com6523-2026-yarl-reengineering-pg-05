# Preserved classroom automation

The original files from `.github/workflows/` are stored here as inactive reference material. Their content is unchanged. The original workflow paths and commits remain available in Git history.

The personal archive disables GitHub Actions. The current GitHub login also lacks the `workflow` permission needed to upload active workflow paths, so the archive moves those paths without deleting historical commits or requesting broader access.

These workflows target classroom grading and/or upstream project automation. Review their repository assumptions and credentials before intentionally restoring any workflow to `.github/workflows/`.

The upstream `.github/dependabot.yml` configuration is also preserved here as `dependabot.yml`. Moving it out of `.github/` prevents the personal preservation copy from scheduling upstream dependency-update pull requests.
